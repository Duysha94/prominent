# WordPress deliverable

Two files install the whole site:

| File | What it is |
|---|---|
| `ak-zeyna-child.zip` | The child theme — design system, motion, all page templates, CF7 styling |
| `import/ak-content.xml` | The content — pages, menu, six case studies, four journal entries, the Contact Form 7 form |

Install order and everything else: **`ak-zeyna-child/README.md`**
(the same file ships inside the zip).

Prerequisites: the Zeyna parent theme (ThemeForest) and the free
Contact Form 7 plugin.

The zip is rebuilt from `ak-zeyna-child/` — edit the directory, not the
archive.
